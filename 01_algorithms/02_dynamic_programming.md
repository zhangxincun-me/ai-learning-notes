# 动态规划

> 标签：#算法 #模板题 #动态规划 #最优化

---

## 做题心得

动态规划题最重要的不是一上来写代码，而是先想清楚 `dp` 数组到底表示什么。只要状态定义清楚，转移方程、初始化和遍历顺序通常都会自然长出来。

---

## 一句话总结

动态规划是一种把大问题拆成相互重叠的小问题，并通过保存子问题答案来避免重复计算的算法思想，常用于求最值、方案数和可行性。

---

## 核心问题

动态规划解决的是“当前答案可以由更小规模问题推出来”的问题。

常见输入：

- 一个数组、字符串、网格、背包容量或若干限制条件。
- 题目通常要求在这些条件下做选择、统计方案或判断能否达成目标。

常见输出：

- 最大值 / 最小值。
- 方案数量。
- 是否可行。
- 某个位置、区间或容量对应的最优结果。

适用场景：

- 问题可以拆成子问题。
- 子问题之间会重复出现。
- 当前状态的答案可以由之前状态转移得到。
- 选择过程具有“最优子结构”，也就是整体最优可以由局部子问题的最优答案组成。

不适用场景：

- 每个子问题只会出现一次，直接递归或分治就够了。
- 当前选择会影响非常复杂的未来状态，但无法用有限状态描述。
- 题目只需要简单贪心，并且局部最优就能保证全局最优。

---

## 核心思想

动态规划的本质是：用空间换时间。

暴力递归会反复计算同一个子问题，而动态规划把这些子问题的答案存下来。之后再遇到同一个问题时，直接查表即可。

做动态规划时，核心要想清楚四件事：

1. 状态定义：`dp[i]` 或 `dp[i][j]` 表示什么。
2. 状态转移：当前状态从哪些旧状态推出来。
3. 初始化：最小子问题的答案是什么。
4. 遍历顺序：怎样保证计算当前状态时，依赖的旧状态已经算过。

比如爬楼梯问题：

```text
每次可以爬 1 阶或 2 阶，问爬到第 n 阶有多少种方法。
```

如果定义：

```python
dp[i] = 爬到第 i 阶的方法数
```

那么第 `i` 阶可以从第 `i - 1` 阶爬 1 步上来，也可以从第 `i - 2` 阶爬 2 步上来：

```python
dp[i] = dp[i - 1] + dp[i - 2]
```

这就是状态转移。

---

## 核心操作 / 关键步骤

### 1. 定义状态

作用：明确 `dp` 数组中每个位置的含义。

思路：不要急着写转移方程，先用一句话说清楚 `dp[i]` 表示什么。

常见定义：

```python
dp[i] = 考虑前 i 个元素时的答案
dp[i] = 以第 i 个元素结尾的答案
dp[i][j] = 考虑前 i 个元素、容量为 j 时的答案
dp[i][j] = 字符串 s 的前 i 个字符和字符串 t 的前 j 个字符的答案
```

状态定义不同，转移方程和遍历顺序也会不同。

---

### 2. 写状态转移方程

作用：说明当前状态如何由之前的状态推出来。

思路：站在当前状态，看最后一步可能从哪里来。

常见形式：

```python
dp[i] = dp[i - 1] + dp[i - 2]
dp[i] = max(dp[i], dp[j] + value)
dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight] + value)
dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
```

写转移方程时可以多问一句：

```text
如果我要得到当前答案，最后一步发生了什么？
```

---

### 3. 初始化

作用：给最小规模的问题一个明确答案，避免后续转移没有起点。

思路：根据 `dp` 的定义来初始化，而不是凭感觉填 `0` 或 `1`。

例子：

```python
# 爬楼梯
dp[0] = 1
dp[1] = 1

# 最短路径
dp[0][0] = grid[0][0]

# 背包问题
dp[0][j] = 0
```

初始化错了，后面的转移即使写对，答案也会错。

---

### 4. 确定遍历顺序

作用：保证计算当前状态时，它依赖的状态已经被算出来。

思路：看状态转移方程依赖谁，就先算谁。

常见顺序：

- `dp[i]` 依赖 `dp[i - 1]`：从左到右遍历。
- `dp[i][j]` 依赖上方和左方：从上到下、从左到右遍历。
- 0-1 背包一维优化：容量从大到小遍历。
- 完全背包一维优化：容量从小到大遍历。

## 模板代码

### 基础一维 DP 模板

```python
def solve(nums):
    n = len(nums)
    dp = [0] * n

    # 初始化
    dp[0] = nums[0]

    for i in range(1, n):
        # 根据题意写状态转移
        dp[i] = max(dp[i - 1], nums[i])

    return dp[-1]
```

---

### 基础二维 DP 模板

```python
def solve(grid):
    m = len(grid)
    n = len(grid[0])
    dp = [[0] * n for _ in range(m)]

    # 初始化
    dp[0][0] = grid[0][0]

    for i in range(m):
        for j in range(n):
            if i == 0 and j == 0:
                continue

            from_up = dp[i - 1][j] if i > 0 else float("inf")
            from_left = dp[i][j - 1] if j > 0 else float("inf")
            dp[i][j] = min(from_up, from_left) + grid[i][j]

    return dp[m - 1][n - 1]
```

### 记忆化搜索模板

```python
from functools import cache


def solve(n):
    @cache
    def dfs(i):
        if i == 0:
            return 1
        if i == 1:
            return 1

        return dfs(i - 1) + dfs(i - 2)

    return dfs(n)
```

记忆化搜索适合“递归思路很清楚，但直接递归会超时”的题。

### 0-1 背包模板

每个物品只能选一次。

```python
def knapsack_01(weights, values, capacity):
    dp = [0] * (capacity + 1)

    for weight, value in zip(weights, values):
        for j in range(capacity, weight - 1, -1):
            dp[j] = max(dp[j], dp[j - weight] + value)

    return dp[capacity]
```

容量倒序遍历，是为了防止同一个物品被重复选择。

---

### 完全背包模板

每个物品可以选无限次。

```python
def knapsack_complete(weights, values, capacity):
    dp = [0] * (capacity + 1)

    for weight, value in zip(weights, values):
        for j in range(weight, capacity + 1):
            dp[j] = max(dp[j], dp[j - weight] + value)

    return dp[capacity]
```

容量正序遍历，是为了允许当前物品被重复选择。

## 复杂度

动态规划的复杂度通常由状态数量和每个状态的转移次数决定。

```text
时间复杂度 = 状态数量 * 每个状态的转移次数
空间复杂度 = dp 数组大小
```

常见情况：

- 一维 DP：时间复杂度 $O(n)$，空间复杂度 $O(n)$。
- 二维 DP：时间复杂度 $O(mn)$，空间复杂度 $O(mn)$。
- 背包 DP：时间复杂度 $O(nC)$，空间复杂度 $O(C)$，其中 `C` 是背包容量。

如果当前状态只依赖前一个或前几个状态，空间复杂度通常可以优化。

## 常见题型

### 1. 线性 DP

状态沿着数组或字符串从左到右推进。

典型题：

- 爬楼梯。
- 打家劫舍。
- 最大子数组和。
- 最长递增子序列。

例子：

```python
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

---

### 2. 网格 DP

状态在二维网格中移动，通常只能从上方或左方转移。

典型题：

- 不同路径。
- 最小路径和。
- 礼物最大价值。

例子：

```python
dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
```

---

### 3. 背包 DP

在容量限制下选择物品，求最大价值、方案数或是否可行。

典型题：

- 0-1 背包。
- 完全背包。
- 分割等和子集。
- 零钱兑换。

例子：

```python
dp[j] = max(dp[j], dp[j - weight] + value)
```

---

### 4. 区间 DP

状态表示一个区间 `[i, j]` 的答案，通常从短区间推到长区间。

典型题：

- 戳气球。
- 石子合并。
- 最长回文子序列。

例子：

```python
dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j])
```

---

### 5. 字符串 DP

两个字符串或一个字符串的前缀之间进行状态转移。

典型题：

- 最长公共子序列。
- 编辑距离。
- 回文子串。
- 正则表达式匹配。

例子：

```python
if s[i - 1] == t[j - 1]:
    dp[i][j] = dp[i - 1][j - 1] + 1
else:
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
```

## 易错点

- `dp[i]` 的含义没有定义清楚，就直接写转移方程。
- 初始化和状态定义不匹配。
- 遍历顺序写反，导致用到了还没算出来的状态。
- 一维优化后，0-1 背包和完全背包的容量遍历方向混淆。
- 没有处理空数组、长度为 `1`、容量为 `0` 等边界情况。
- 求最大值时初始值应该足够小，求最小值时初始值应该足够大。
- 方案数问题和最值问题的转移方式不同，不要混在一起。

---

## 相关变形

- 记忆化搜索：自顶向下写法，适合递归关系明显的题。
- 滚动数组：当二维 DP 只依赖上一行时，可以压缩空间。
- 状态压缩 DP：用二进制表示集合状态，常见于排列、子集选择问题。
- 树形 DP：状态定义在树节点上，由子节点向父节点转移。
- 数位 DP：按数字位数统计满足条件的数字数量。
- 概率 DP：状态保存期望值或概率。
